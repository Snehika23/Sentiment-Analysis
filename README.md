### 📝 [Sentiment Analysis — Amazon Food Reviews](https://github.com/Snehika23/Sentiment-Analysis-Major-Project)
> B.Tech Final Year Project | Published in *Journal of Interdisciplinary Cycle Research* (March 2024)

- Analysed **568,454 Amazon Fine Food reviews** using NLP and machine learning
- Built a full pipeline: text cleaning, TF-IDF vectorisation, and multi-class sentiment classification (positive / neutral / negative)
- Trained and compared **Logistic Regression (73.4%)**, Random Forest (72.7%), and SVM (68.9%)
- Visualised key sentiment drivers using **word clouds** and frequency distributions
- 📄 **[Read the Published Paper (JICR, ISSN: 0022-1945)](https://github.com/Snehika23/Sentiment-Analysis-Major-Project/blob/main/11-JICR-MARCH-2024.pdf)**
- 🔧 **Tech:** Python | NLTK | Scikit-learn | TF-IDF | Matplotlib | Google Colab
